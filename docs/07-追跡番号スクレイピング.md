# 追跡番号スクレイピング

メルカリ・ヤフオク・ヤフフリ・ラクマの **購入した取引** から追跡番号を集めて、
スプレッドシート「メルカリ自動抽出」の商品IDと突き合わせて書き込みます。

## なぜスクレイピングなのか

4 サイトとも購入者向けの公開 API がありません。
また **商品ID（`m50204465032` / `n1212071910`）は出品IDであって取引IDではない** ため、
商品IDを入り口にした追跡番号の逆引きはそもそも存在しません。

そこで逆方向に回します。

```
購入履歴一覧 → 各取引ページを開く → ページ内の商品リンクから商品IDを取る
                                  → 同じページから追跡番号を取る
                                  → 商品IDでスプレッドシートの行に突き合わせる
```

## 取れないケースがある

**匿名配送は購入者に伝票番号を開示しません。**

| 配送方法 | 追跡番号 |
|---|---|
| らくらくメルカリ便 / ゆうゆうメルカリ便 | ほぼ取れない（配送状況のみ） |
| おてがる配送（ヤフオク・ヤフフリ） | ほぼ取れない（配送状況のみ） |
| かんたんラクマパック | ほぼ取れない（配送状況のみ） |
| 出品者が自己手配（ゆうパック・宅急便など） | 取れることが多い |

番号が取れなかった行は `追跡番号` が空になり、`配送状況`（発送済み・配達完了など）だけ入ります。
**全件は埋まらない前提で使ってください。**

## 使い方

### 1. 準備

```bash
pnpm install
npx playwright install chromium
```

### 2. ログイン（初回と、セッションが切れたとき）

```bash
node scripts/scrape-tracking.mjs --login
```

ブラウザが 4 サイト分のタブで開きます。**手でログインしてください**（2 段階認証もここで通します）。
終わったらターミナルで Enter を押すと、ログイン状態を確認して `data/browser-profile/` に保存します。

パスワードはスクリプトを一切通りません。保存されるのはブラウザの Cookie だけです。

> `data/` は `.gitignore` 済みです。ログイン情報がコミットされることはありません。

### 3. 取得

```bash
# まず 1 件だけで動作確認
node scripts/scrape-tracking.mjs --sites メルカリ --limit 1 --dump

# 全サイト
node scripts/scrape-tracking.mjs --out data/tracking.csv
```

出力される CSV は次の形です。

| 商品ID | プラットフォーム | 追跡番号 | 配送業者 | 確度 | 配送状況 | 取引URL | 取得日時 |
|---|---|---|---|---|---|---|---|
| m50204465032 | メルカリ | 421355667788 | ヤマト運輸 | high | 配達完了 | ... | ... |
| m73843671206 | メルカリ | | | | 発送済み | ... | ... |

`確度` が `low` の行は、ラベル（「お問い合わせ番号」など）が無く**桁数だけで拾った候補**です。
電話番号や注文番号を誤って拾っている可能性があるので、目視で確認してください。

### 4. スプレッドシートに書き込む

サービスアカウントを 1 つ用意します。

1. Google Cloud でサービスアカウントを作り、JSON キーをダウンロード
2. Google Sheets API を有効化
3. **スプレッドシートを、そのサービスアカウントのメールアドレスに「編集者」で共有**（忘れると 403）
4. `.env` に設定を書く

```bash
GOOGLE_SERVICE_ACCOUNT_JSON=/path/to/service-account.json
TRACKING_SPREADSHEET_ID=11r-Y_xO6z9mPArRIY4mzYwBPjE7I5zmHtwZJtfaf134
```

書き込む内容を先に確認します。

```bash
node scripts/scrape-tracking.mjs --dry-run
```

問題なければ実行します。

```bash
node scripts/scrape-tracking.mjs
```

シートの見出し行から `商品ID` 列を探し、`追跡番号` と `配送状況` の列が無ければ右端に追加して、
商品IDが一致する行だけを更新します。既存の列やほかの行には触りません。

## 既存の Apps Script との関係

シート「メルカリ自動抽出」は Apps Script `merucari_data()` が Gmail から生成しています。
あの関数は最後に **`sp.clear()` でシート全体を消してから書き直す** ので、
このスクリプトで書いた追跡番号は次回の `merucari_data()` 実行で消えます。

先に `merucari_data()` を走らせ、その後でこのスクリプトを走らせる順番にしてください。
順番を固定できない場合は、`merucari_data()` を全消し＆再作成ではなく差分追記に直す必要があります。

## ページ構造が変わって取れなくなったら

各社とも予告なく DOM を変えます。`--dump` を付けると `data/dump/<サイト>/` に
HTML と本文テキストが落ちるので、そこを見て `scripts/lib/tracking-sites.mjs` を直します。

```bash
node scripts/scrape-tracking.mjs --sites ヤフオク --limit 3 --dump
```

直す箇所は 2 つだけです。

- `linkSelector` / `linkPattern` … 一覧から取引ページの URL を集める条件
- `itemIdFrom` … 取引ページから商品IDを取り出す正規表現

追跡番号そのものは CSS セレクタではなく**本文全体への正規表現**で拾っているので、
レイアウト変更では壊れません（`LABELLED` / `SHAPED` を見てください）。

## 注意

各社の利用規約は自動アクセスを禁止しています。自分のアカウントの自分の取引に限って使い、
`--delay`（既定 2,500ms）を短くしすぎないでください。
