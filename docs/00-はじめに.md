## いま何ができていて、何が残っているか

| | 状態 |
|---|---|
| 設計・プログラム | ✅ **できている**（このリポジトリの中身） |
| 動作確認 | ✅ **できている**（テストも自動で回るようにした） |
| データの置き場所を用意する | ⬜ **あなたの作業**（30分くらい・無料で始められる） |
| スプレッドシートの中身を移す | ⬜ 置き場所ができたら私がやります |

**残っているのは「置き場所を用意する」だけです。**
これは私（Claude）には代われません。あなたのメールアドレスとクレジットカードで
アカウントを作る作業だからです。それ以外は私が引き受けます。

## なぜ「置き場所」が必要なのか

いまはデータが Google スプレッドシートの中にあります。
これをアプリから読み書きできる場所に移す必要があります。その置き場所が **Supabase** です。

```
  今                          これから

  スプレッドシート            Supabase（データの置き場所）
       ↑                           ↑         ↑
   みんなで直接開く          大元アプリ   納品アプリ
                            （あなた）  （納品担当者）
```

スプレッドシートだと「開ける人には全部見える」ので、外注先に仕入金額まで見えてしまいます。
Supabase に置けば「この人にはこの行だけ」と決められます。

## 手順1: Supabase のアカウントを作る（10分）

1. https://supabase.com を開く
2. 右上の **Start your project** を押す
3. GitHub アカウント（いまお使いのもの）でログイン
4. **New project** を押して、次を入力する

   | 項目 | 入れる値 |
   |---|---|
   | Name | `bussan-kanri`（何でもよい） |
   | Database Password | 好きなパスワード。**必ずメモする**（後で使う） |
   | Region | **Northeast Asia (Tokyo)** を選ぶ |
   | Plan | Free で始められる |

5. **Create new project** を押す。準備に 2〜3分かかります

> 料金について: 無料枠はデータベース 500MB までです。
> いまのスプレッドシートは全部合わせても数MBなので、当分は無料で足ります。
> 写真を大量に保存すると超える可能性があるので、そのときは Pro（月25ドル）に上げます。

---

## 手順2: 3つの文字列をメモする（2分）

プロジェクトができたら、左メニューの **⚙ Project Settings → API** を開きます。
次の3つをコピーして、メモ帳などに貼っておいてください。

| 画面上の名前 | どんなものか | 扱い |
|---|---|---|
| **Project URL** | `https://xxxx.supabase.co` のような住所 | 人に見せてOK |
| **anon public** | `eyJ...` で始まる長い文字列 | 人に見せてOK |
| **service_role** | `eyJ...` で始まる別の長い文字列 | ⚠️ **絶対に人に見せない・GitHubに貼らない** |

`service_role` は「全部のデータを無条件で読み書きできる鍵」です。
データを移すときに一度だけ使います。**Slack やメールに貼らないでください。**

## 手順3: メモをここに渡す

手順2でメモした **Project URL** と **anon public** の2つを、私に伝えてください。
（`service_role` は渡さないでください。後述の方法で、あなたの手元だけで使います）

そこから先は私がやります。

- データベースに表と権限設定を作る
- スプレッドシートの中身を移す
- 数が合っているか突き合わせる
- アプリを公開して、URLをお渡しする

## 用語

| 言葉 | 意味 |
|---|---|
| **Supabase** | データの置き場所。表計算でいう「スプレッドシート本体」にあたるもの |
| **マイグレーション** | 「こういう表を作れ」という指示書。`supabase/migrations/` の中のファイル |
| **RLS** | 「誰にどの行を見せるか」の設定。外注先に他人の仕入金額を見せないための仕組み |
| **CI** | 変更するたびに自動でテストを回す仕組み。壊れたら GitHub に赤いバツが出る |
| **CSV** | 表計算の中身をテキストにした形式。スプレッドシートから書き出せる |
| **SKU** | 商品1点ごとの管理番号。`2340-EEMM-20260916-1296` のあれ |
| **anon key / service_role key** | データベースに入るための鍵。前者は弱い鍵、後者は全権限のマスターキー |

## よくある質問

**Q. スプレッドシートは消えますか？**
いいえ。移したあともそのまま残ります。しばらくは両方に入力して、
数字が合うことを確認してから切り替えるのが安全です。
古物台帳は3年間の保存義務があるので、スプレッドシートは**書き込み禁止にして残して**ください。

**Q. 途中でやめられますか？**
はい。Supabase のプロジェクトを消せば元どおりです。スプレッドシートは無傷です。

**Q. 納品担当者は何をインストールしますか？**
何も要りません。URLをスマホで開いて、ホーム画面に追加するだけです。

**Q. 納品担当者に仕入金額が見えませんか？**
見えません。画面に出していないだけでなく、データベース側で遮断しています。
アプリを改造されても取れません。これは自動テストで毎回確認しています。

**Q. 私がやらないといけないのは結局どれですか？**
**手順1と手順2だけ**です。あとは私が進めます。
