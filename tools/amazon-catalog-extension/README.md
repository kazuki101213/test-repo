# Amazon 商品リスト登録

Amazon.co.jpの商品ページを開くと、右下に「商品リスト」が自動表示される。管理アプリにログイン済みのタブを同じChromeプロファイルで開いておく。拡張機能が選択中のASINを商品リストと照合する。未登録のときは入力欄を確認し、「商品リストに追加」で保存する。登録できるアカウントは管理アプリの権限に従う。

「Keepa設定」でAPIキーを保存する。キーはこのChromeプロファイルの拡張機能専用ストレージに置き、KeepaへのHTTPS照会に使う。「Keepaデータを取得」で過去1か月の購入表示、30日・90日のランキング降下回数と新品・中古の平均価格を表示する。取得できた型番・メーカーは空欄のときに補完する。

Keepaへの新規照会はボタンを押したときだけ行う。6時間以内の取得結果は再利用する。トークンが尽きたら再取得までの目安を表示する。30日以内の前回データがあれば取得日時とともに表示できる。商品登録はKeepaの設定・残高に関係なく利用できる。

## ビルド

リポジトリのルートから Node.js 24 以降で実行する。

```
node tools/amazon-catalog-extension/build.mjs <出力フォルダー>
node --test tools/amazon-catalog-extension/keepa.test.mjs
```

Chromeの `chrome://extensions` でデベロッパーモードをオンにし、「パッケージ化されていない拡張機能を読み込む」で、`manifest.json` がある出力フォルダーを選ぶ。管理アプリの公開変更やDBマイグレーションは不要。
